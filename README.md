# ЖКУ Контроль

Веб-приложение для управления оплатой жилищно-коммунальных услуг. Дипломный проект.

Три отдельных кабинета: для жителей, сотрудников управляющей компании и её администратора.

## Что умеет

**Публичная часть**
- Проверка задолженности по лицевому счёту без регистрации
- Страница с описанием сервиса и FAQ по ролям

**Кабинет плательщика**
- Список квитанций с фильтрами по периоду и статусу
- Оплата через МИР и СБП (демо)
- История платежей и детали каждой квитанции

**Кабинет бухгалтера**
- Реестры начислений, оплат и должников
- Выгрузка документов в PDF, Word и CSV
- Акт сверки оплат, отчёт по выручке
- Статистика с графиком по месяцам и фильтром по объекту

**Кабинет администратора компании**
- Управление сотрудниками и их ролями
- Реестр домов с деревом: город → район → дом
- Статистика оплат с выбором периода через календарь
- Выгрузка отчётов в PDF и Word

## Стек

- **React 19** + **Vite**
- **React Router v7** — клиентский роутинг
- **Lucide React** — иконки
- **localStorage** — хранение данных на клиенте
- **Express + PostgreSQL** — серверная часть (синхронизация данных)
- Чистый CSS без UI-библиотек

## Запуск

```bash
# установить зависимости
npm install

# запустить фронтенд
npm run dev

# запустить сервер (отдельно)
cd server
node index.js
```

Фронтенд: `http://localhost:5173`

## Структура проекта

```
src/
  features/        # кабинеты по ролям (payer, employee, companyAdmin)
  pages/           # публичные страницы (главная, авторизация, партнёрство)
  components/      # общие компоненты (хедер, карточки, роутинг по ролям)
  utils.js         # хелперы: форматирование, работа с данными
  config.js        # константы и демо-данные
  api.js           # синхронизация с сервером
```
